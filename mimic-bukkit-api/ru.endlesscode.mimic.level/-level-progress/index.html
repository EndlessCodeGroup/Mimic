LevelProgress

@ApiStatus.NonExtendable
interface LevelProgress(source)

Snapshot of a player's progress on a level track. The maximum level and experience requirements are the ones that apply to this player now, so they may differ between players on the same track.

Values are read together and may be stale right after a write, so don't cache them. Progress objects are equal if all their values are equal.

Create it with the builder:

LevelProgress.level(5).minLevel(1).build();
LevelProgress.level(5).minLevel(0).maxLevel(99).exp(10.0).expToNextLevel(100.0).build();
