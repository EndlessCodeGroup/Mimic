MinecraftItemsRegistry

class MinecraftItemsRegistry : BukkitItemsRegistry(source)

Items service implementation using material name as itemId.

Supported payloads in getItem:

  • String with item components in the format of the /give command, for example [damage=10,unbreakable={}]. Components syntax depends on the server version. Invalid components are ignored.

  • String with ItemMetaPayload in HOCON format, see ItemMetaPayload.parse. Name and lore support MiniMessage formatting.

  • ItemMetaPayload instance.
