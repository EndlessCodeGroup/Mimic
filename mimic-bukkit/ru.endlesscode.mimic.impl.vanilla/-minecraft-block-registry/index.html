MinecraftBlockRegistry

@ExperimentalMimicApi
class MinecraftBlockRegistry : BukkitBlockRegistry(source)

Block registry implementation using material name as blockId. Supports block state properties in the vanilla format as a payload in setBlock, for example [facing=north].

Contents of blocks holding items, like chests or campfires, are passed to the drops consumer in breakBlock. Shulker boxes keep their contents inside the dropped item.
